# Solo Adventurer client patch

Client files for Jacob's AzerothCore server: `Data\patch-4.MPQ` and the `SoloAdventurer` addon.

## Friends: getting updates

1. Download [UPDATE-WOW.bat](https://raw.githubusercontent.com/jwlower/SoloAdventurer-public-patcher/main/UPDATE-WOW.bat)
   (right-click the link, **Save link as...**) into your WoW folder, next to `Wow.exe`.
2. Whenever Jacob says there's an update, close WoW and double-click `UPDATE-WOW.bat`.

It only downloads files that changed, clears your `Cache` folder when needed, and never touches your
realm address, login, settings or other addons.
